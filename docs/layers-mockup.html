시안 · 화면 층 나누기 · 2026-11-04

메인 화면은 비우고, 나머지는 필요할 때 위로

지금은 설명 문장 · 보조 버튼 · 옵션을 모두 메인 화면에 펼쳐 둡니다. 모바일답게 층을 나눕니다. 메인에는 “어디에 무엇이 있나”와 주된 행동 하나만 두고, 나머지는 누를 때 올라오는 시트, 한 번에 답하는 토스트, 나중에 묻는 알림으로 옮깁니다.

네 개의 층

L0 · 메인보이는 것만

지도 · 목록 · 주된 버튼 하나. 설명 문장, 보조 버튼, 옵션 칩은 두지 않습니다.

L1 · 토스트방금 한 일 · 한 번에 답하기

아래에서 잠깐 뜨는 한 줄 + 버튼 2~3개. 되돌리기, 빠른 확인, “아까 그거 어떻게 됐어요?”

L2 · 시트누른 것의 자세한 것

아래에서 반쯤 올라오는 창. 물건 하나의 기록 · 옵션, 장보기 한 줄의 담기 개수.

L3 · 전체 화면 · 알림키보드 입력, 나중에 묻기

글을 쓰는 입력은 전체 화면(규칙 그대로). 앱 밖에 있을 때 물을 것은 알림으로.

바뀌는 것

  • 기록 화면에서 되돌리기 버튼을 뺍니다. “버림 → 다시 넣기”도 뺍니다(버린 건 다시 넣을 일이 아님). 방금 한 실수는 지금처럼 토스트의 되돌리기로.
  • 물건 시트의 행동을 꺼내기 · 다 씀 · 옮기기로 나눕니다. 가위 · 줄자처럼 쓰고 돌려놓는 건 “꺼내기”, 휴지처럼 줄어드는 건 “씀”.
  • 꺼낸 물건은 기록에 “밖에 있음”. 2시간 뒤 앱을 열면 토스트로, 앱을 안 열면 저녁에 알림으로 한 번 묻습니다. 한 번 눌러 끝.
  • 같은 방식으로 묻는 것: 기한이 지난 것(“요거트 버렸어요? 먹었어요?”), 돌려받을 날이 지난 것.

바뀌는 것

  • 지도: 아래 띠 카드 3개(먼저 챙기기 · 돌려받기 · 떨어져 가요)와 보고서 링크를 검색창 아래 알약 한 줄로. 누르면 시트에 목록. 지도가 화면 대부분을 씁니다.
  • 보관함 · 공간: 화면 위 설명 문장을 없애고, 처음 한 번만 말풍선 팁. 여러 개 고르기는 꾹 누르기 → 아래 행동 바.
  • 물건 넣기: 이름 · 수량 · 넣을 곳만 기본. 기한 · 최소 수량 · 메모는 알약을 누르면 그 칸이 열림. 아이콘 · 분류는 자동으로 고르고, 알약을 눌러야 고르는 시트.
  • 설정: 긴 한 장 → 계정 · 더하기 기능 · 데이터 · 정보 네 칸, 누르면 들어가는 화면.
  • 가족: “이 폰 물건 합치기” 카드를 상시 두지 않고, 우리 집에 처음 들어올 때 한 번 묻는 시트. 초대코드도 시트.
  • 영수증 목록: 줄은 체크 · 이름 · 개수만, 이름 고치기는 줄을 누르면 시트.
