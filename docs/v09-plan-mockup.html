v0.9 계획 · 2026-10-28 · v0.8 1~3 · 5 · 6 다음

넣기는 더 쉽게, 그리고 스토어로

v0.8로 가족이 같은 집을 쓰게 됐습니다. v0.9는 물건을 넣는 수고를 줄이고(사진 · 바코드), 폰 밖에서도 보이게 하고(위젯 · 리포트), 비공개 테스트로 스토어에 올리는 단계입니다. 이번에도 단계마다 APK로 확인받고 넘어갑니다.

단계

1

가족 쓰기 다듬기

두 폰 실사용에서 나오는 것 정리: 코드로 들어온 사람의 원래 폰 물건 “우리 집에 합치기”, 같은 물건을 둘이 동시에 고칠 때 알림, 확성기 줄에 가족 얼굴, 가족 소식 “하루 한 번 묶어서” 옵션.

선행 없음 · 두 폰으로 확인 부탁
2

사진 한 장으로 넣기

찍으면 요정이 이름 · 분류 · 개수를 추천하고 고르기만 하면 됩니다. 여러 개가 찍히면 한 번에 여러 줄. 서버 함수가 사진을 보고(Haiku 5.5 기본), 사진은 저장하지 않습니다. 하루 한도는 AI 검색과 함께 셉니다.

선행 필요: Anthropic API 키 → GitHub secret ANTHROPIC_API_KEY (서버 Secret Manager로 옮김)
3

바코드로 넣기

바코드를 비추면 상품명 · 용량을 채웁니다. 같은 바코드를 다시 찍으면 그 물건 수량 +1. 상품 정보는 공공데이터(식약처 바코드연계제품정보)부터, 못 찾으면 이름만 직접.

선행 필요: 공공데이터포털 인증키 → GitHub secret DATA_GO_KR_KEY
4

홈 화면 위젯

앱을 열지 않고: 먼저 챙길 것 · 장보기 개수, 누르면 바로 검색. 가족이 바꾸면 위젯도 바뀝니다.

선행 없음
5

월간 리포트 · 내보내기

이번 달 넣은 것 · 쓴 것 · 기한이 지나 버린 것, 가장 많이 쓴 소모품. 엑셀(CSV)로 내보내기, 백업 파일로 저장 · 되살리기.

선행 없음
6

네이버 로그인

no_categorized_error 원인 확정: 앱 상태(개발 중이면 멤버 등록), 안드로이드 패키지명 · 서명 해시, SDK 로그. 고칠 수 없으면 버튼을 숨기고 출시.

선행 필요: 네이버 개발자센터 멤버 관리 · API 설정 화면 확인
7

비공개 테스트 (Play)

업로드 키로 AAB(aab.yml), App Check(Play Integrity) 켜기, 개인정보처리방침 페이지, 스토어 등록정보(스크린샷은 골든 테스트 화면), 테스터 12명 14일.

선행 필요: Play Console 개발자 계정 · 앱 만들기 · ANDROID_UPLOAD_PASSPHRASE · 테스터 12명 이메일
8

요정 플러스 구독

Play 결제 월 · 연 구독. 무료와 차이: 가족 인원, AI(검색 · 사진) 하루 한도 없음, 바코드 · 사진 넣기 무제한. 서버가 영수증을 확인해 집의 limit을 바꿉니다.

선행 필요: Play 결제 프로필 · 구독 상품 등록
