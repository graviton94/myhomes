단계

1

가족 쓰기 다듬기

코드로 들어온 사람의 원래 폰 물건 “우리 집에 합치기”, 같은 물건을 둘이 동시에 고칠 때 알림, 확성기 줄에 가족 얼굴, 가족 소식 “하루 한 번 묶어서”.

선행 없음 · 두 폰으로 확인 부탁
2

AI 비용 계측 · 크레딧

모든 AI 호출(Jev · Haiku)을 서버가 집별로 기록: 호출 수 · 토큰 · 추정 원가. 집마다 월 크레딧(검색 1, 영수증 3, 사진 5)에서 빼고, 다 쓰면 규칙(단어 검색)으로. 지금 “하루 50번/사람”도 이 방식으로 바꿉니다. 매달 원가 보고서(Actions).

선행 없음 (Jev 호출당 단가는 확인 필요: 콘솔 또는 청구서 한 장)
3

영수증으로 넣기

찍으면 폰 안에서 글자를 읽고(ML Kit 한국어, 무료 · 오프라인), 규칙이 상품 줄 · 수량 · 가격 줄을 가립니다(core, 테스트 포함). “CJ햇반210g*3” 같은 줄임말만 서버가 글자로 정리(사진은 보내지 않음, 1장 약 0.6원). 넣을 곳은 최근 자리 추천, 한 번에 여러 줄.

선행 없음 (정리 단계에 Haiku 를 쓰면 ★ Anthropic API 키, 없으면 규칙 + Jev 로 시작)
4

바코드로 넣기 (식품)

식약처 C005로 식품 이름만. 같은 바코드는 우리 집이 기억해 두 번째부터 서버에 안 물음. 못 찾으면 이름만 직접. 공산품은 영수증으로.

선행 없음 (키 있음)
5

홈 화면 위젯

앱을 열지 않고: 먼저 챙길 것 · 장보기 개수, 누르면 바로 검색. 가족이 바꾸면 위젯도 바뀜.

선행 없음
6

월간 리포트 (PDF)

이번 달 넣은 것 · 쓴 것 · 기한 지나 버린 것, 많이 쓴 소모품, 가족별 한 줄. 폰에서 PDF로 만들어 카톡 · 메일로 공유. 서버 비용 없음.

선행 없음
7

비공개 테스트 · 요정 플러스

업로드 키 AAB, App Check(Play Integrity), 개인정보처리방침, 스토어 등록정보, 테스터 12명 14일. 같은 Play Console 에서 구독 상품(크레딧 방식) 등록, 네이버 로그인 다시 확인.

선행 필요: Play Console 앱 · ANDROID_UPLOAD_PASSPHRASE · 테스터 12명 · 결제 프로필
8

사진 한 장으로 넣기 (신중히)

먼저 우리 집 물건 사진 100장 평가 세트 → 모델 · 사진 크기별 정확도와 원가를 재고, 목표(이름 맞춤 85%, 1장 1원 이하)를 넘을 때만 엽니다. 사진은 512px로 줄여 보내고 저장하지 않음.
