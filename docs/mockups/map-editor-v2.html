지도 편집 시안 3

휴대폰으로 열어서 직접 만져 보세요.

  • 편집 → 저장 / 취소 · 편집을 눌러야 바뀌어요.
    취소하면 편집 전 그대로 돌아가요.
  • 겹쳐도 일단 놓여요 · 겹친 방은 빗금으로 보여요.
    저장할 때 한 번만 물어봐요.
  • 옮기기 · 방 어디든 잡고 바로 끌어요.
    고르지 않은 방도 돼요.
  • 크기 · 고른 방 둘레 점선 안 어디든 잡고 끌어요.
    모서리 쪽을 잡으면 대각선으로 늘어나요.
  • 끝없는 칸 · 위 · 왼쪽으로도 얼마든지 늘려요.
  • 화면 이동 · 빈 곳을 한 손가락, 두 손가락은 확대.
