LOGIN-01 · 로그인

정할 것과 규칙

  • 소개 문구 3장은 위처럼 찾기 · 넣기 · 가족으로 바꿈. 기한 알림 소개는 부가 기능이라 뺌.
  • 로그인에 성공하면 바로 홈. 이미 로그인한 사람에게는 로그인 화면을 건너뜀.
  • 설정의 "소개 다시 보기"는 소개 3장 → 로그인 화면까지 다시 보여 줌. 로그인돼 있으면 소개만.

LOGIN-02 · 업데이트 후 한 번

한 번만, 막지 않게

  • 업데이트 뒤 처음 열 때 한 번만 아래 시트로 권함. "나중에"를 누르면 다시 묻지 않음.
  • 화면을 가로막는 전체 화면 대신 시트라서, 닫으면 바로 쓰던 홈.
  • 로그인해도 휴대폰 안 물건은 그대로(아직 동기화 없음).

HOME-03 · 뜻으로 찾음

동작

  • 글자 · 초성 · "어딨어" 같은 물음말은 지금처럼 휴대폰에서 바로 찾음.
  • 이름으로 못 찾을 때만 입력을 멈추고 0.8초 뒤 요정 서버에 물음(하루 50회 한도 그대로).
  • 결과를 누르면 그 방이 열리고 물건이 반짝임(지금 기능).
  • 요정 동그라미 버튼과 대화 시트는 없앰. 요정 말은 검색창 아래 한 줄.
  • 탭은 홈 · 공간 · 기한 · 가족 4개(찾기 탭 없앰). 지도 탭은 4단계에서.
