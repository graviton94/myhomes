# Play Console 상품 (붙여넣기용)

앱이 찾는 제품 ID 는 `plus_monthly` 와 `dust_500` 두 개다. ID 는 글자 그대로 넣는다(만든 뒤에는 못 바꾼다).
가격은 여기서 정하지 않는다: 콘솔에 넣은 값이 앱에 그대로 나온다. 아이콘은 `docs/store/products/` 에 있다.

## 1. 플러스 (정기 결제)

수익 창출 → 제품 → 정기 결제 → 정기 결제 만들기

| 칸 | 넣을 것 |
|---|---|
| 제품 ID | `plus_monthly` |
| 이름 (ko-KR) | 플러스 |
| 이름 (en-US) | Plus |
| 설명 (ko-KR) | 매달 요정 가루 1,500. 설명으로 찾기 · 영수증 정리 · 사진으로 넣기를 넉넉하게 써요. |
| 설명 (en-US) | 1,500 fairy dust every month for search by meaning, receipt tidying and adding from a photo. |
| 혜택 1 (ko / en) | 매달 요정 가루 1,500 / 1,500 fairy dust every month |
| 혜택 2 (ko / en) | 무료의 10배 / Ten times the free amount |
| 혜택 3 (ko / en) | 언제든 해지 / Cancel any time |

기본 요금제 추가:

| 칸 | 넣을 것 |
|---|---|
| 기본 요금제 ID | `monthly` |
| 유형 | 자동 갱신 |
| 결제 기간 | 1개월 |
| 유예 기간 | 3일 (기본값 그대로) |
| 가격 | 정하는 값 (대한민국 기준으로 넣고 "다른 국가 가격 자동 설정") |

저장한 뒤 기본 요금제 **활성화**. (아이콘 칸이 보이면 `plus_monthly-512.png`.)

## 3. 서버 계정 초대 (구매 확인용)

서버가 "이 구매가 진짜인가"를 Google 에 물으려면, 서버의 계정이 Play Console 에 들어와 있어야 한다.

1. Play Console 맨 처음 화면(모든 앱 목록)의 왼쪽 메뉴 → **사용자 및 권한**
2. **새 사용자 초대**
3. 이메일 주소: `787038949126-compute@developer.gserviceaccount.com`
4. 액세스 만료일: 없음 (비워 둠)
5. **앱 권한** 탭 → **앱 추가** → 우리집요정(Home Fairy) 선택 → 적용
6. 열리는 권한 목록에서 두 가지만 체크:
   - **재무 데이터, 주문, 취소 설문조사 응답 보기** (View financial data)
   - **주문 및 구독 관리** (Manage orders and subscriptions)
7. **적용** → **사용자 초대** → 확인

서비스 계정은 초대 메일을 받지 않고 바로 "활성"이 된다. 권한이 서버에 닿기까지 몇 분에서 길면 하루가 걸릴 수 있다.

## 4. 시험

라이선스 테스터 계정으로 스토어(테스트 트랙)에서 설치한 1.0.6 → 설정 → 플러스 · 요정 가루 → 가격이 보이면 상품이 연결된 것. 한 주머니를 사서 "고마워요! 요정 가루가 들어왔어요"가 뜨고 가루가 500 늘면 서버 확인까지 된 것.
"구매를 마치지 못했어요"가 뜨면 3번(서버 계정)이 아직 안 닿은 것일 가능성이 가장 크다. 결제는 완료되지 않은 채로 남았다가 다음에 다시 시도된다(테스트 결제는 3일 뒤 자동 환불).
