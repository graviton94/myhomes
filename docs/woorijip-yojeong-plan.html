탭 수가 곧 리텐션

이런 앱이 실패하는 이유는 입력이 귀찮아서입니다. 그래서 세 동작의 탭 수 상한을 정하고, 모든 화면을 이 기준으로 설계합니다. 홈 첫 줄에 세 버튼을 항상 둡니다.

넣기

3탭 이내

  1. 1찍기: 카메라가 바로 열림
  2. 2이름: 최근 이름 칩 탭 또는 입력 (AI 연동 후 자동 추천)
  3. 자동위치: 마지막으로 넣은 보관함이 기본값
  4. 3저장하고 다음 찍기: 서랍 하나를 연속으로 등록

옮기기

담기 1탭 + 내려놓기 1탭

  1. 1요정 주머니에 담기: 여러 곳에서 여러 개를 담을 수 있음
  2. 이동집 안을 돌아다니는 동안 주머니는 화면 아래에 떠 있음
  3. 2여기에 내려놓기: 도착한 보관함에서 한 번에 내려놓기

빼기

1탭

  1. 1−1 꺼내 쓰기: 물건 카드의 가장 큰 버튼
  2. 1다 썼어요 / 버렸어요: 수량 0으로, 이력에 사유 기록
  3. 자동최소 수량 아래로 떨어지면 장보기 목록에 추가 제안

생김새

  • 선: 진한 갈색 3px 선 하나로 그려 작은 크기(24px)에서도 알아볼 수 있게

쓰는 규칙

  • 한 화면에 한 번만. 정보보다 앞에 나서지 않기
  • 말풍선은 한 줄, 행동으로 이어지는 말만 (“먼저 먹을 게 3개 있어요”)
  • 장식용 그림은 화면 낭독기에서 숨기고, 말풍선 글자만 읽힘
  • 움직임은 등록 완료 때 한 번 폴짝. 동작 줄이기 설정이면 정지
