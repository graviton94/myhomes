왜 만드는가

“가위 어디 있어?”

물건 위치를 한 사람만 알고 있습니다. 그 사람이 집에 없으면 온 집을 뒤집니다.

“이거 또 샀어?”

있는 줄 몰라서 같은 물건을 다시 삽니다. 창고와 베란다가 특히 그렇습니다.

“이거 언제까지야?”

냉장고 안쪽에서 소비기한 지난 식품이 나옵니다. 누가 언제 넣었는지도 모릅니다.

지켜야 할 규칙

  • 터치 영역 48dp 이상, 간격 8dp 이상하단 탭, 칸, 스테퍼 버튼 모두 손가락 기준으로 설계합니다.ux · Touch Target Size / Touch Spacing
  • 이모지 대신 SVG 아이콘Lucide 계열 선 아이콘을 쓰고, 아이콘만 있는 버튼에는 접근성 라벨(“뒤로 가기”)을 붙입니다.app · Icon Button Labels
  • 드래그에는 항상 대안칸 사이 드래그와 똑같은 일을 “옮기기” 시트에서 탭만으로 할 수 있어야 합니다.app · Dragging Alternatives / No Gesture-Only Actions
  • 색만으로 상태를 말하지 않기소비기한 배지에는 “내일까지”, “D-3” 같은 글자를 함께 씁니다. 분류 색도 아이콘과 같이 씁니다.ux · Color Only
  • 본문 16sp, 글자 크기 확대 대응시스템 글자 크기를 키워도 경로가 잘리지 않고 두 줄로 넘어가게 합니다.app · Base Font Size / Dynamic Type Support
  • 움직임은 150~200ms, 동작 줄이기 존중칸 이동과 시트 열림에만 짧게 쓰고, 기기 설정에서 동작 줄이기를 켜면 끕니다.app · Duration & Easing / Respect Reduced Motion

    상용화 포인트

    어떻게 돈이 되는가

    빈 자리

    냉장고 관리 앱은 식품만, Sortly 같은 재고 앱은 소상공인용입니다. 가족이 함께 쓰는 집 전체의 위치 기반 재고는 아직 주인이 없습니다.

    가장 큰 리스크

    이런 앱은 처음 2주 열심히 입력하다 지쳐서 이탈합니다. MVP는 연속 등록, 필수 2항목, 소비기한 빠른 입력으로 입력 비용을 줄이고, v2의 AI 인식이 결정타입니다.

    쓸수록 떠나기 어려운 구조

    집 전체 지도와 가족 이력이 쌓일수록 다른 앱으로 옮기기 어렵습니다. 가족 초대는 자연스러운 바이럴 경로이기도 합니다.
