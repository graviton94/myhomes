# 우리집요정

가족이 함께 쓰는 홈 인벤토리 앱. 집요정이 집 안 물건의 위치·수량·소비기한을 기억합니다.

- 기획서(목업 포함): [docs/woorijip-yojeong-plan.html](docs/woorijip-yojeong-plan.html)
- 핵심 3동작: 찍어서 넣기(3탭) · 여러 개 선택(수량 팝업) 후 일괄 옮기기 · 1탭 빼기
- 로그인: 카카오 · 네이버 · Google
- 일정: Android MVP → 기본 기능 완성 → AI 사진 인식 연동 → Android 정식 출시 → 2개월 후 iOS
- 백엔드: Firebase (Auth · Firestore · Storage · FCM · Cloud Functions), us-central1, 카카오·네이버는 커스텀 토큰
- 수익: 무료+가벼운 광고(보상형 광고로 AI 추가) · 요정 플러스 구독(광고 제거) · 쿠팡 파트너스 장보기 연결
- 디자인: UI UX Pro Max 기반 Flat Design + 따뜻한 톤(감색 · 잎새 · 꿀), 크레용 손그림 집요정 캐릭터
